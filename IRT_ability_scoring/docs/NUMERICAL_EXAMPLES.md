# Numerical examples

Every number below was produced by the app's own functions (`scoring`, `irt_models`) with the default settings:
prior N(0, 1), 41 Gauss–Hermite nodes, search range ±5, tolerance 10⁻⁶, start θ⁽⁰⁾ = 0, D = 1. Page 10
("Numerical examples A–D") recomputes them live with the current sidebar settings, and `tests/test_scoring.py`
checks them against independent calculations (direct optimisation, adaptive integration, brute-force pattern
enumeration) and `tests/test_reference.py` against irtQ, mirt and TAM.

Hand check for Example A, pattern x = (1, 0, 1) at θ = 0: P = (0.73106, 0.5, 0.26894), so
ℓ′(0) = Σ(x − P) = 0.26894 − 0.5 + 0.73106 = 0.5 and ℓ″(0) = −ΣP(1 − P) = −(0.19661 + 0.25 + 0.19661) = −0.64322;
the first Newton step is 0 + 0.5/0.64322 = 0.77733 — the first row of the table.

Example B reproduces the specification: MLE(A = (1, 0)) = −0.4196, MLE(B = (0, 1)) = +0.4196, TCC = 0 for both.
Example D reproduces (P₀, P₁, P₂) = (0.26894, 0.46212, 0.26894) at θ = 0 for item G1.
